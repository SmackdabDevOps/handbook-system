# Express Stack Profile

This stack profile defines the standard structure and conventions for Express.js projects aligned with the System Delivery Playbook.

## Overview

Express is a minimal and flexible Node.js web application framework that provides a robust set of features for building REST APIs. This stack profile ensures consistency across Express-based services in the Smackdab ecosystem.

## Directory Structure

```
project-root/
├── src/
│   ├── routes/          # Express route handlers
│   ├── middleware/      # Custom middleware (auth, validation, error handling)
│   ├── services/        # Business logic layer
│   ├── schemas/         # Zod or Joi validation schemas (DTOs)
│   ├── models/          # Database models
│   ├── utils/           # Utility functions
│   ├── config/          # Configuration loader
│   └── index.ts         # Application entry point
├── openapi/
│   ├── paths/           # OpenAPI path definitions
│   └── schemas/         # OpenAPI schema definitions
├── docs/
│   ├── user-stories/    # Requirements (from handbook)
│   ├── business-rules/  # Constraints (from handbook)
│   └── test-plans/
│       └── validation-specs/  # Test specifications
├── handbook/            # Synced handbook content
├── scripts/
│   ├── validation/      # Validation scripts
│   └── generators/      # Code generation scripts
├── tests/
│   ├── unit/            # Unit tests
│   ├── integration/      # Integration tests
│   ├── contracts/       # API contract tests
│   └── e2e/             # End-to-end tests
├── architecture/        # Generated by npm run endpoints:validate
├── package.json
├── tsconfig.json
└── .env                 # Configuration (never commit)
```

## Route Handler Structure

Each route handler file should follow this pattern:

```typescript
// src/routes/example.ts
import { Router, Request, Response, NextFunction } from 'express';
import { validateRequest } from '../middleware/validate-request';
import { authenticate } from '../middleware/authenticate';
import { ExampleSchema } from '../schemas/example.schema';
import { ExampleService } from '../services/example.service';
import { asyncHandler } from '../utils/async-handler';

const router = Router();
const exampleService = new ExampleService();

/**
 * GET /api/example/:id
 * @openapi
 * /example/{id}:
 *   get:
 *     tags: [Example]
 *     parameters:
 *       - in: path
 *         name: id
 *         required: true
 *         schema:
 *           type: string
 */
router.get('/:id',
  authenticate,
  asyncHandler(async (req: Request, res: Response) => {
    const result = await exampleService.findById(req.params.id);
    res.json({ data: result, message: 'Success', responseType: 'success' });
  })
);

/**
 * POST /api/example
 * @openapi
 * /example:
 *   post:
 *     tags: [Example]
 *     requestBody:
 *       required: true
 *       content:
 *         application/json:
 *           schema:
 *             $ref: '#/components/schemas/ExampleCreate'
 */
router.post('/',
  authenticate,
  validateRequest(ExampleSchema.create),
  asyncHandler(async (req: Request, res: Response) => {
    const result = await exampleService.create(req.body);
    res.status(201).json({ data: result, message: 'Created', responseType: 'success' });
  })
);

export default router;
```

## Middleware Chain Patterns

### Standard Middleware Order

Middleware should be applied in this order:

```typescript
// src/index.ts
import express from 'express';
import { notFoundHandler } from './middleware/not-found';
import { errorHandler } from './middleware/error-handler';
import { requestLogging } from './middleware/request-logging';
import { corsHandler } from './middleware/cors';
import exampleRoutes from './routes/example';

const app = express();

// 1. Request logging (first)
app.use(requestLogging);

// 2. CORS
app.use(corsHandler);

// 3. Body parsing
app.use(express.json());
app.use(express.urlencoded({ extended: true }));

// 4. Routes
app.use('/api/example', exampleRoutes);

// 5. 404 handler (before error handler)
app.use(notFoundHandler);

// 6. Global error handler (last)
app.use(errorHandler);

export default app;
```

## Error Handling Middleware

### Async Error Wrapper

```typescript
// src/utils/async-handler.ts
import { Request, Response, NextFunction } from 'express';

export const asyncHandler = (fn: (req: Request, res: Response, next: NextFunction) => Promise<any>) => {
  return (req: Request, res: Response, next: NextFunction) => {
    Promise.resolve(fn(req, res, next)).catch(next);
  };
};
```

### Global Error Handler

```typescript
// src/middleware/error-handler.ts
import { Request, Response, NextFunction } from 'express';
import { AppError } from '../utils/app-error';
import { logger } from '../utils/logger';

export const errorHandler = (err: Error, req: Request, res: Response, next: NextFunction) => {
  logger.error('Request error', {
    path: req.path,
    method: req.method,
    error: err.message,
    stack: err.stack,
  });

  if (err instanceof AppError) {
    return res.status(err.statusCode).json({
      data: null,
      message: err.message,
      responseType: err.responseType || 'error',
      errors: err.errors,
    });
  }

  // Unhandled error
  res.status(500).json({
    data: null,
    message: 'Internal server error',
    responseType: 'error',
  });
};
```

### Application Error Class

```typescript
// src/utils/app-error.ts
export class AppError extends Error {
  constructor(
    public statusCode: number,
    public message: string,
    public responseType: string = 'error',
    public errors?: Record<string, string[]>
  ) {
    super(message);
    Object.setPrototypeOf(this, AppError.prototype);
  }
}
```

## Request Validation with Zod

### Schema Definition

```typescript
// src/schemas/example.schema.ts
import { z } from 'zod';

export const ExampleSchema = {
  create: z.object({
    name: z.string().min(1, 'Name is required').max(255),
    email: z.string().email('Invalid email'),
    age: z.number().int().positive().optional(),
  }),

  update: z.object({
    name: z.string().min(1).max(255).optional(),
    email: z.string().email().optional(),
  }),

  id: z.object({
    id: z.string().uuid('Invalid ID format'),
  }),
};
```

### Validation Middleware

```typescript
// src/middleware/validate-request.ts
import { Request, Response, NextFunction } from 'express';
import { ZodSchema } from 'zod';
import { AppError } from '../utils/app-error';

export const validateRequest = (schema: ZodSchema) => {
  return (req: Request, res: Response, next: NextFunction) => {
    try {
      const validated = schema.parse(req.body);
      req.body = validated;
      next();
    } catch (error: any) {
      const errors = error.errors?.reduce((acc: any, err: any) => {
        const path = err.path.join('.');
        if (!acc[path]) acc[path] = [];
        acc[path].push(err.message);
        return acc;
      }, {}) || {};

      throw new AppError(400, 'Validation failed', 'validation_error', errors);
    }
  };
};
```

## Service Layer Pattern

Services encapsulate business logic and database access:

```typescript
// src/services/example.service.ts
import { ExampleModel } from '../models/example.model';
import { AppError } from '../utils/app-error';
import { logger } from '../utils/logger';

export class ExampleService {
  async findById(id: string) {
    const record = await ExampleModel.findByPk(id);
    if (!record) {
      throw new AppError(404, 'Record not found');
    }
    return record;
  }

  async create(data: any) {
    try {
      const record = await ExampleModel.create(data);
      logger.info('Record created', { id: record.id });
      return record;
    } catch (error: any) {
      logger.error('Failed to create record', { error: error.message });
      throw new AppError(500, 'Failed to create record');
    }
  }

  async update(id: string, data: any) {
    const record = await this.findById(id);
    await record.update(data);
    logger.info('Record updated', { id });
    return record;
  }

  async delete(id: string) {
    const record = await this.findById(id);
    await record.destroy();
    logger.info('Record deleted', { id });
    return { id };
  }
}
```

## Authentication Middleware

```typescript
// src/middleware/authenticate.ts
import { Request, Response, NextFunction } from 'express';
import { AppError } from '../utils/app-error';
import { verifyToken } from '../utils/auth';

export const authenticate = (req: Request, res: Response, next: NextFunction) => {
  const token = req.headers.authorization?.split(' ')[1];

  if (!token) {
    throw new AppError(401, 'No authorization token provided');
  }

  try {
    const user = verifyToken(token);
    (req as any).user = user;
    next();
  } catch (error) {
    throw new AppError(401, 'Invalid or expired token');
  }
};
```

## Testing Conventions

### Unit Tests

Test individual functions and services:

```typescript
// tests/unit/example.service.test.ts
import { ExampleService } from '../../src/services/example.service';

describe('ExampleService', () => {
  let service: ExampleService;

  beforeEach(() => {
    service = new ExampleService();
  });

  it('should create a record', async () => {
    const result = await service.create({ name: 'Test' });
    expect(result).toHaveProperty('id');
  });
});
```

### Integration Tests

Test API endpoints with real database:

```typescript
// tests/integration/example.test.ts
import request from 'supertest';
import app from '../../src/index';

describe('Example API', () => {
  it('should create an item', async () => {
    const response = await request(app)
      .post('/api/example')
      .send({ name: 'Test Item' })
      .expect(201);

    expect(response.body).toHaveProperty('data.id');
  });
});
```

### Contract Tests

Verify API responses match OpenAPI spec:

```typescript
// tests/contracts/example.contract.ts
import request from 'supertest';
import app from '../../src/index';

describe('Example API Contract', () => {
  it('GET /api/example/:id returns correct schema', async () => {
    const response = await request(app)
      .get('/api/example/123')
      .expect(200);

    expect(response.body).toHaveProperty('data');
    expect(response.body).toHaveProperty('message');
    expect(response.body).toHaveProperty('responseType');
  });
});
```

## Key Principles

1. **Contract-First Development:** OpenAPI specs are the source of truth
2. **Error Handling:** All errors inherit from AppError with consistent formatting
3. **Validation:** Use Zod for runtime validation of request bodies
4. **Testing:** Write tests before implementation (TDD)
5. **Logging:** Use structured logging with context information
6. **Middleware Chain:** Follow the standard middleware order
7. **Service Layer:** Keep business logic separate from route handlers
8. **Async/Await:** Always wrap async handlers with asyncHandler utility
